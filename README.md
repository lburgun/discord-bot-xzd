# Discord Bot

Un bot Discord simple et fonctionnel développé en Python.

Made by **Burgun Leo**

---

## Fonctionnalités

* Commandes de base (+help)
* Gestion des variables d'environnement sécurisée avec un fichier `.env`
* Prêt à être étendu avec de nouvelles commandes et événements

---

## Prérequis

* **Python** (3.10 ou supérieur)
* Un token de bot récupéré sur le [Discord Developer Portal](https://discord.com/developers/applications)
