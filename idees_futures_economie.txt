====================================================================
           IDÉES POUR LA SUITE - ÉVOLUTION DU BOT
====================================================================

1. Le Crafting (La Forge) ⛏️⚒️
--------------------------------------------------------------------
- Fichiers concernés : mine.py / miner.py / inventory.py
- Actuellement : Les minerais (Fer, Or, Charbon) sont juste vendus dans le +wagon.
- L'idée : Créer un système de +craft. Les joueurs peuvent combiner des minerais 
  pour créer des objets introuvables au shop.
  * Exemple : 10x Fer + 5x Charbon = Pioche en Acier (augmente le rendement de la mine).
  * Exemple : 5x Or + 1x Bijou = Bague Légendaire.
- L'impact : Les minerais deviendront la ressource la plus précieuse du serveur, 
  tout le monde en voudra sur le Marketplace.

2. L'Industrie et les Entreprises 🏭💼
--------------------------------------------------------------------
- Fichier concerné : entreprise.py
- Actuellement : Les entreprises génèrent de l'argent juste avec la commande +work.
- L'idée : Ajouter un système de "Matières Premières".
  * Pour que l'entreprise produise ses revenus, le patron doit acheter ou injecter 
    des ressources (ex: besoin de 50x Fer par semaine pour tourner).
- L'impact : Les patrons d'entreprises deviendront les plus gros acheteurs sur le 
  Marketplace, créant une vraie économie circulaire (les mineurs vendent aux patrons).

3. Applications "Dark Web" sur le Téléphone 📱💻
--------------------------------------------------------------------
- Fichiers concernés : phone.py / apps.py / catalogue.py
- L'idée : Si un joueur possède le Smartphone, il débloque la commande +phone. 
  Dedans, on peut créer une application "DarkNet".
  * Utilité : C'est le seul endroit où l'on peut acheter les outils illégaux 
    (le Rossignol, la Viande empoisonnée) ou blanchir de l'argent volé sans se faire repérer.

4. Synergie des Métiers (Jobs) 🧑‍🏫
--------------------------------------------------------------------
- Fichiers concernés : jobs.py / work.py
- L'idée : Donner un "Passif" (Bonus) à chaque métier.
  * Policier : A +30% de chance de réussir un +arrest et voit les primes doublées.
  * Livreur : Réduit la taxe du Marketplace de 5%.
  * Banquier : Son coffre-fort protège 60% de son argent au lieu de 40%.

5. Le Casino "VIP" (High Rollers) 🎰♠️
--------------------------------------------------------------------
- Fichiers concernés : blackjack.py / slot.py / roulette.py
- L'idée : Créer des "Salons VIP" inaccessibles aux joueurs normaux.
  * Condition d'entrée : Posséder un objet de catégorie "Luxe" ou une Propriété.
  * L'avantage : Les mises maximums explosent, et les probabilités de gagner aux 
    machines à sous sont légèrement meilleures.
